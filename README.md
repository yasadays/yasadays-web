## Running

Assuming `pnpm` as the package manager. Adapt it to your package manager of choice.

```sh
pnpm i # Yoink the dependencies

pnpm run dev # Start a dev server
pnpm run build # Build for production
pnpm run preview # Preview production (build first!)
pnpm run astro # Run astro cli
pnpm run pretty # Format all files with Prettier
```
